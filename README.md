# MindSpark '26 - Lucky Wheel 🎡

An interactive, dark-glassmorphic Spin the Wheel lucky draw web application for **MindSpark '26** (COEP Technological University, Pune).

## Features
- **Deterministic Discount Logic**: Calibrated probability slices mapping directly to competition discounts (50%, 40%, 20%).
- **Interactive Mechanical Wheel**: Fluid canvas wheel physics with needle flapper physics, ratchet click audio synthesized via Web Audio API, and fanfare celebration.
- **Searchable Event Selector**: Live type-to-search dropdown covering all official competitions and modules.
- **Micro-Animations & Visual Aesthetics**: Dynamic `PixelBlast` canvas shader background, authentic Preloader, and full-screen synchronized confetti.
- **Instant Registration Gateway**: Direct redemption redirects to CrwdCtrl competition portals.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
